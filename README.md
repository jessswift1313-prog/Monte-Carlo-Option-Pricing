# Monte Carlo Option Pricing

A small numerical-finance project for pricing European call options under the Black–Scholes model.

The project starts from the closed-form Black–Scholes price, reproduces it with Monte Carlo simulation, studies the convergence of the estimator, and then applies antithetic variates to reduce variance.

The main workflow is:

1. implement the Black–Scholes benchmark;
2. price the same option using Monte Carlo simulation;
3. measure standard error, confidence intervals, and RMSE;
4. check the expected $N^{-1/2}$ convergence rate;
5. compare standard Monte Carlo with antithetic sampling under a fixed simulation budget.

## Model

Under the Black–Scholes model, the stock follows geometric Brownian motion under the risk-neutral measure:

$$
dS_t = rS_t \, dt + \sigma S_t \, dW_t.
$$

The terminal stock price can be simulated directly using

$$
S_T = S_0 \exp\left(\left(r - \frac{1}{2}\sigma^2\right)T + \sigma\sqrt{T}Z\right), \qquad Z \sim N(0,1).
$$

For a European call with strike price $K$, the payoff at maturity is

$$
(S_T - K)^+ = \max(S_T - K, 0).
$$

Its time-0 value under risk-neutral pricing is

$$
C_0 = e^{-rT} \mathbb{E}^{\mathbb{Q}}[(S_T - K)^+].
$$

## Monte Carlo estimator

Using $N$ independently simulated terminal stock prices, the Monte Carlo estimator is

$$
\hat{C}_N = e^{-rT}\frac{1}{N}\sum_{i=1}^{N}(S_T^{(i)} - K)^+.
$$

The implementation also estimates the standard error and reports an approximate 95% confidence interval.

For an unbiased Monte Carlo estimator with finite variance,

$$
\mathrm{SE}(\hat{C}_N) \propto N^{-1/2}.
$$

This means reducing the statistical error by a factor of 2 requires roughly 4 times as many simulation paths.

## Convergence experiment

I compare the Monte Carlo estimates with the analytical Black–Scholes price using

```text
N = 10^2, 10^3, 10^4, 10^5, 10^6
```

simulation paths.

For each value of $N$, the pricing experiment is repeated several times. I record:

- mean price estimate
- mean standard error
- empirical RMSE relative to Black–Scholes
- estimator variance across repeated runs
- mean confidence interval width

The main convergence check is

$$
\mathrm{RMSE} \approx \mathrm{SE} \propto N^{-1/2}.
$$

The log-log plot compares the observed RMSE with the expected $N^{-1/2}$ rate.

## Antithetic variates

V1 uses antithetic variates as a simple variance reduction method.

Instead of using unrelated normal shocks, I generate $Z$ together with $-Z$.

Both have the same standard normal distribution, so the expected option value is unchanged. However, the two resulting call payoffs tend to move in opposite directions, which can create negative covariance between them.

The paired observation is

$$
A = \frac{Y(Z) + Y(-Z)}{2}.
$$

Its variance is

$$
\mathrm{Var}(A) = \frac{1}{4}\left[\mathrm{Var}(Y(Z)) + \mathrm{Var}(Y(-Z)) + 2\mathrm{Cov}(Y(Z), Y(-Z))\right].
$$

When the covariance term is negative, the variance of the pair average is reduced.

## Fixed-budget comparison

To make the comparison fair, standard Monte Carlo and antithetic Monte Carlo are evaluated using the same target path budget.

For each method, I compare:

- mean price estimate
- estimator variance
- RMSE

A representative run with $N = 100000$ gave:

| Metric | Standard MC | Antithetic MC |
| --- | ---: | ---: |
| Mean estimate | 10.449834 | 10.445185 |
| Estimator variance | 0.00286638 | 0.00092640 |
| RMSE | 0.052644 | 0.030408 |

The empirical variance reduction is calculated as

$$
1 - \frac{\widehat{\mathrm{Var}}(\hat{C}_{anti})}{\widehat{\mathrm{Var}}(\hat{C}_{standard})}.
$$

For the run above, the estimator variance was reduced by about **67.7%**.

The exact value changes between executions because the experiments use fresh random samples.

## What I wanted to test

The main questions behind the project were:

- Can Monte Carlo reproduce the Black–Scholes price?
- Does the numerical error decrease at approximately $N^{-1/2}$?
- Do the reported standard errors agree with the empirical behaviour of the estimator?
- Can antithetic sampling reduce variance under the same simulation budget?
- How should numerical error be separated from model error?

The Black–Scholes model is useful here because the closed-form solution gives a known benchmark. This makes it possible to test the numerical method before moving to models where no analytical solution is available.
